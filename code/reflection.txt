# This assignment mainly taught me about data lineage, which means each step of the pipeline adds new columns but never changes or deletes the old ones. Because the raw "38h 30m" stays in the table next to cleaned 38.5 you can easily check where a number came from. I also learned to use Series.apply when a function only needs one column, and DataFrame.apply with axis=1 when it needs two values from the same row. Most of my mistakes on this assignment were because I did not inspect the data close enough. I added up the raw "hours" text instead of the already cleaned "hours_worked" numbers, filtered for a pay_type value that did not exsist and forgot to round pay to cents. Next time, I will look at what values a column actually has before filtering it, read error messages more carefuly to troubleshoot faster and run ruff check before every commit.
